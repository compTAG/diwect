# diwect-vs-wect

Experiments for the ongoing work:
_An Omnidirectional WECT: Closed-Form Computation of the Directionally-Integrated Weighted Euler Characteristic Transform_.
An arXiv preprint is available here: [arXiv:2611.22101](https://arxiv.org/abs/2611.22101).


`src/` contains the source code/implementation for the DIWECT.

`experiments/` contains the code for running experiments and generating the
figures used in the manuscript.
